# 大地工作台（本机版）

一个跑在自己电脑上的页面：把 Slack、Google Drive 任务硬盘、alaco.ai 网站后台、Gmail 和 Claude Code 放进同一个界面。页面只是壳，真正干活的是你电脑上的 Claude Code（命令行版），所以不需要服务器，也不需要另外授权。

## 1. 文件

| 文件 | 作用 |
|---|---|
| `server.mjs` | 本机桥接程序（Node 24，零依赖，只听 127.0.0.1:8850）。起 Claude Code 进程、转发后台接口、人物权限、硬规则、真实用量、历史对话、审计。 |
| `hooks/guard.mjs` | 硬规则：Claude Code 每次用工具前先过这里（官方 PreToolUse 钩子），整目录删除、动密钥、强推代码、后台删商品之类直接拒。启动时复制到运行数据目录并写 `hooks.json`。 |
| `index.html` / `app.css` / `app.js` | 页面：办公室场景、情报、Slack、硬盘、后台、Claude 面板。 |
| `brain-core.mjs` / `brain-seed.mjs` | 协作部分（v25）：任务表、经验→批准→写进模版、留言和通知、文件存档、分工表、成员钥匙。给各人自己的 Claude Code 开 `/mcp`、`/hook/*`、`/files`、`/client/*` 四个入口（凭钥匙）；页面走 `/api/brain/*`。数据在运行数据目录的 `brain/`。 |
| `client/` ＋ `接入我的Claude.command` | 把一台电脑上的 Claude Code 接到工作台：连接、四个钩子（开对话・每句话前・对话结束・压缩前）、`dadi put/get` 存档命令。 |
| `words.mjs` | 把工具名、参数、后台路径翻成中文的字典（页面上不出现代码）。 |
| `slacklib.mjs` | Slack 直连：用自建应用 Dadi Workbench 的用户令牌直接调 Slack Web API，输出和连接器同格式；令牌失效自动退回连接器。 |
| `drivelib.mjs` | Google Drive 直连：读写本机 Google Drive 桌面版挂载的共享云端硬盘（`~/Library/CloudStorage/GoogleDrive-…/共享云端硬盘/`），文件编号从扩展属性 `com.google.drivefs.item-id#S` 读，和连接器一致；Google 文档／表格的正文本机没有，仍交给连接器。 |
| `maillib.mjs` | Gmail 直连：用 Google 账号的「应用专用密码」走 IMAP 读收件箱里没读的邮件，输出和连接器同格式；密码只存本机 `mail.json`（0600）。 |
| `adminlib.mjs` / `admin-mcp.mjs` | 后台直连：登录、token 保存、路径守卫；给 Claude Code 用的 `admin_get`／`admin_write`／`admin_upload`（传图片）工具。 |
| `tools/album_cards.py` / `assets/` | 「ALA 商品页」模版用的相册卡片生成器和 Ala&Co 字标（本机 Python 3＋Pillow）。 |
| `report.mjs` | Markdown → PDF（用本机 Google Chrome 无头打印）。 |
| `config.json` | 配置（见第 4 节）。 |
| `启动大地工作台.command` | 双击启动（服务已在跑时只开浏览器）。 |
| `安装后台服务.command` / `卸载后台服务.command` | 装成开机自启的后台服务（launchd，`ai.alaco.dadi-workbench`）。 |
| `运行测试.command` | 跑单元测试＋无头 Chrome 冒烟测试。 |
| `test/` | 测试与替身 Claude Code（`fake-claude.mjs`，离线测页面用）。 |

运行数据不在这个文件夹里，在 `~/Library/Application Support/dadi-workbench/`：`admin.json`（后台 token，0600，7 天）、`slack.json`（Slack 用户令牌，0600）、`mail.json`（Gmail 应用专用密码，0600）、`state.json`、`templates.json`（模版库，含 trash）、`secret`（本次启动的口令）、`mcp.json`／`hooks.json`／`guard.mjs`（给 Claude Code 的工具与硬规则配置，启动时重写）、`box/`（取数进程用的空文件夹）、`uploads/`（ask ala 里传的附件）、`log/`（服务日志、审计 `audit.log`、调试记录只在放了 `debug` 开关文件时才写，自动只留 20 份）、`reports/`（后台报告 PDF）。

## 2. 安装与启动

1. 装好命令行版 Claude Code（`~/.local/bin/claude`），终端里跑一次 `CLAUDE_CONFIG_DIR=$HOME/.claude-team claude auth login`，用公司 Team 席位登录（个人 Max 不用于工作台）；连接器（Slack、Google Drive、Gmail、Google Calendar）在 claude.ai 用公司账号连好，Slack 还要在命令行版里 `/mcp` 授权一次。
2. 双击 `安装后台服务.command`（只需一次）。以后开机自动起，浏览器打开 http://127.0.0.1:8850/ 就是工作台。
3. 第一次在页面「网站后台」楼里用自己的后台账号登录一次（token 存本机，7 天）。

重启服务：`launchctl kickstart -k gui/$(id -u)/ai.alaco.dadi-workbench`。日志：`~/Library/Application Support/dadi-workbench/log/service.log`。

## 3. 怎么用

- **左侧竖栏**（v22）：顶上的 a 回办公室；下面四个每天要看的窗口直接摆着——**情报・后台・Slack・模版**（各带自己的角标，再点一次同一个＝关掉）；最底下一个 **菜单** 钮收着硬盘・系统・历史对话和快捷指令。（v21 曾把全部窗口收进菜单，Souki 20261109 否：重要的要拿出来。）旧说明：顶上的 a 回办公室；中间一个 **菜单** 钮（角标＝情报＋Slack 未读＋后台待办的合计），点开是两组——**窗口**（情报、Slack、硬盘、后台、模版、系统、历史对话，一次开一个，再点关）和 **快捷指令**（生成今天的后台报告／写周报／今天谁找我／汇总情报／待发货／店铺流水／库存一览／去主频道／派任务／刷新／切换人物／系统状态／最近操作）；最下面是「我是谁」（切换人物、改形象）。底部正中的橙色圆钮是 **ask ala** 对话框。
- **模版＝指令 skill**（v23，20261109；v24 目录改成**和网站后台菜单一样的树**：网站运营／店铺／管理员区 → 各页面，模版挂在对应页面下；四个模块（选品・渠道・运营・服务）只作筛选标签）。一张张卡：一张卡五段：**触发・输入・规则・程序・结果**。两种：**任务型**＝一句话＋附件 → Claude Code 照定稿规则做完、工作台程序做机械活 → 用 `tpl_result` 交回**一屏结果卡**（你看、复制或点一次）；**提醒型**＝规则 → 每天 9:00 工作台自己算成**「今日」**（情报窗口顶上一屏，Slack 主频道同一份），每条提醒带「做」「打开」「已处理」。看和运行谁都可以；新建、改规则、删除、收进口径要带 `templates` 权限的人物。
  - **商品是一条链**（模版 1、7 的详情页里有「商品链」面板，输入款号就能看走到哪一步）：**7 采购单（新款）**（后台「采购」：读桌面上供应商的报价单和素材 → 字段表给人确认 → 在 Chrome 里用采购 app 自己的函数建单・入库・分配到网站 → 拿到款号 slug、后台 draft）→ **1 商品编辑**（后台「商品」）→ 訳文 → 公开（人在后台点）。数字只从报价单来，不重打。
  - 自带七条：**1 商品编辑**（任务・商品页程序，金样＝ALA 商品页：款号＋照片 → Claude 起草 → 工作台校验・生成金样版式卡片 → 结果卡里预览＋「上传到后台（draft）」，管理员点两次；「改细节」进整页表单；公开在后台由人点）；**2 税理士提问**（任务：问题＋凭证 → 日文邮件草稿一屏，带公司固定口径；「回信收进规则」把税理士回复抽成口径，`tpl_rule_add` 弹确认卡后进「已确认口径」）；**3 订单・咨询・退款超时提醒**（服务）、**4 税务・行政日历**（运营，日期写在规则里「月-日｜事项｜提前天数」）、**5 mospace 月结・役員借入**（渠道）、**6 入库后还没商品页**（选品，一键带款号进模版 1）。
  - 代码：`skills.mjs`（今日引擎 computeToday／日历解析 parseCalendar／结果卡 results.json）、`product.mjs`（商品页程序）、`server.mjs` 的 TPL_SEED／tplRunText／todayEnsure／todayMorning、`admin-mcp.mjs` 工具 product_schema・product_load・draft_put・list_photos・tpl_result・tpl_rule_add、`app.js` 的 renderTpl／resCard／todayHTML。
  - **编号**：每条模版有一个不变的短号（模版 1、模版 2…），卡片和详情都显示。在 ask ala 里直接说「按模版 3 执行：…」或「按模版《ALA 商品页》…」，工作台会把那条模版的正文接在你的话后面一起发给 Claude Code；编号不存在会提示。斜杠命令 `/tpl` 打开模版窗口。
  - **带照片运行**：详情页「加照片／文件」最多 40 个（每个 12MB 内），点「按这条模版执行」时先全部存到本机 `uploads/日期/`，再把路径和模版一起交给 Claude Code（它用 Read 看图）。
  - **模版能用的工具**：`tools/album_cards.py`（按 spec.json 生成 1200×1200 的 ALA 相册卡片：main／point／triple／grid／spec／setcard，版式＝20261106 金样，字标在 `assets/`，需要本机 Python 3 带 Pillow）；后台工具多了 `admin_upload`（把本机一张图片传到后台图片库，返回 url；按「改后台」权限走确认卡）。商品本身由采购区分配后已存在（draft），模版只填内容，不新建、不公开。
  - **自带模版升级**：工作台更新后，自带模版若有新版本（seedRev）且你没改过正文，启动时自动换成新正文（版本号加一）；改过的不动。
- **办公室**是舞台，占满整屏；情报／Slack／硬盘／后台都是居中弹出的窗口，一次一个，点窗外或按 Esc 关。场景里的人会自己走动（去 Slack、去任务硬盘、去后台），冒泡说自己在做什么；Claude Code 忙的时候在楼之间跑。
- **情报**：只放两样——要你处理的事（一条一张卡：来自谁、来源 Slack／Drive／后台／网站／Gmail、时间、摘要；点一条直接打开它所在的窗口，选中的卡上有「回复」「记为任务」「看过了」）和情报汇总（工作台用 Claude Code 写；当天有 Slack 里 Claude 发的例行汇总就直接用那条）。后台数字在「后台」窗口，没做完的工作在「硬盘」窗口，情报里只给一行数字和入口。
- **ask ala** 一条线：本机 Claude Code（回复、建任务、查后台、找文件、今天谁找我）。会改东西的操作先弹确认卡。**20261109 起 Souki 的工作台用他个人的 Max 账号**（souki.zong@gmail.com，登录目录 `~/.claude`，`claudeConfigDir` 留空）；公司 Team 席位（`~/.claude-team`）不再给工作台用。模版自动任务改走公司 API key 的拆分还没做。Slack 里的 Claude 只负责每天的例行汇总。
- **人物**：平时是 **Ki Sou（只读）**——看、回 Slack、动任务硬盘；切成 **管理员** 才能改后台、发邮件、改文件，120 分钟后自动切回。限制是在服务端做的，Claude Code 想绕也绕不过。
- **网站后台 = 状态一览**：三块——网站后台（待发货／咨询／退货／退款／待批／今日・昨日订单＋库存预警・规格异常・服务器报错）、采购（本期售出・毛利・在库・在售・在途・待上架・借款＋补偿・返品・库存分布）、店铺（今日流水・含税・退款・待批・店铺在库＋按支付方式）。点数字卡展开明细清单。不再有巡检按钮和固定指令。
- **后台报告改为手动**：快捷指令「生成今天的后台报告」→ 只读查后台 → PDF 放进「线上网站（ai）/待办」；要放别的文件夹或换格式，直接在 ask ala 里说。没有定时任务、不自动发 Slack。
- **上传**：ask ala 和 Slack 窗口都能带图片／文件——点回形针、拖进来、或粘贴截图；图片 Claude Code 直接看，其它文件存在本机 `uploads/日期/` 再告诉它路径；发到 Slack 的走 Slack 上传。
- **回收站**：硬盘里点开任务硬盘的文件，底部「移入回收站」（两次点击）；这是单独的 `trash` 权限，只给你的两个人物，同事的配置里不加就没有。
- **系统窗口**三页：「状态」——Claude Code 登录状态、后台 token 还剩多久、管理员还剩多久、连接器、服务、刷新节奏，以及 硬规则（开没开、几条）、桌面通知开关、历史对话入口、任务进行窗口开关、今日真实用量；「用量」——按天、按用途（取数／对话／报告／汇总）、按模型的真实 token 数（Claude Code 每次跑完自己报的，不是估算；「折算 US$」只是按 API 牌价换算的分量，Max 不按量收费）；「最近操作」——工作台和 Claude Code 的每一次写操作（含硬规则拒绝、续接对话），按天分组、可筛选、点一条看全文。
- **硬规则**：`hooks/guard.mjs` 里一组不看人物、不看模式的硬拦截（整目录删除、sudo、格式化磁盘、chmod 777、强推／丢弃 git 历史、停掉工作台服务、下载脚本直接执行、动钥匙串／密钥目录、改 .env／口令／工作台数据文件、后台删商品用户订单、改后台账号设置、杀光进程）。拦下的记进「最近操作」。服务端在批准工具时也过同一套规则，双保险。
- **桌面通知**：系统 → 状态 → 桌面通知 打开后，页面不在前台时，做完、要你点头、有人私聊或 @ 你，会弹系统通知，点通知回到对应窗口。
- **任务进行**（Manus 式）：在 ask ala 里让 Claude Code 做事，宽屏右侧弹出一列：任务是什么、每一步用了什么工具、成没成、用时，点一步看它拿到的内容；做完显示轮数、用时和折算分量。可在 ask ala 标题栏「步骤」手动开关，「系统 → 状态」里关掉自动弹出。窄屏不弹，对话里的步骤行点一下也能看内容。
- **历史对话**：ask ala 标题栏「历史」或快捷指令「历史对话」——工作台开过的每一段对话（Claude Code 自己写在登录目录里的记录），能搜关键词、回看、导出 Markdown、「续接这段」接回 ask ala 继续说、「删除」（两次点击确认，记录文件一起删；删的是现在这段就自动开新的一段，记进「最近操作」）。一段＝从开始说到下一次「清空」之间。
- **情报汇总**：由工作台自己用 Claude Code 写（有新消息才写，自动最多半小时一次，走席位份额不另收钱）。工作台不会给 Slack 里的 Claude（Claude Tag，按次收费）发任何消息；它每个工作日 9:00 的例行汇总如果还在发，页面读到当天那条也会显示。
- **苹果式一层**（v20.1，全站）：所有窗口、菜单、竖栏、顶栏都是玻璃（半透明白＋背后模糊＋细高光），标题 28px 细字距收紧，小标题 13px 灰字，卡片半透明白细线无阴影，超椭圆角（`corner-shape:squircle`，Chrome 支持），打开用弹簧曲线（`--spring`）。配色仍是暖白＋黑＋橙。**以后新加的窗口和文字排版照这一套**：标题用 `.phead h2`、小标题用 `h4`、卡片用 `.cardn`，不另写字号和圆角。
- **设计纪律**（v20）：圆角四档（micro 6／tile 12／card 20／pill 999，28 只给窗口外框）、字重 400/600/700、字阶 12/13/15/17/22；Slack 窗口不用 Slack 的蓝紫红，提及、线程、新消息线都用工作台的橙；背景白一律 `--surface`；所有能按的元素按下缩 0.97；悬停规则只在有鼠标的设备生效（`@media (hover:hover)`）；面板入场改用 transition＋`@starting-style`（可打断，时长保留 .55s）；硬盘窗口宽屏两栏、行高 56；ask ala 步骤行的 ⎿ 结果给明文（「读到 25 条消息」「找到 3 个文件」），原文点「看原文」。
- **ask ala 照 Claude Code**（v19）：多行输入（Enter 发送、Shift+Enter 换行、↑ 调出上一句）；输入 `/` 弹命令菜单（/clear 清空、/model 模型与力度、/steps 任务进行窗口、/resume 历史、/cost 用量、/status 系统、/who 切换人物、/stop、/help）；思考过程（✻ 思考，点开看全文）；待办清单卡（TodoWrite）；改文件显示红绿差异、写文件显示内容，确认卡里也是差异；每一步 ⏺ 工具＋⎿ 结果首行，点开看全文；底部状态行（模型、人物、本段轮数、折算）；它忙时再发的话排队，做完自动发。
- **Slack 窗口照 Slack**（v19）：一列式（头像、名字、时间，同一人五分钟内连说归一组）、日期分隔线、上次看到之后的「新消息」线、mrkdwn（*粗体* _斜体_ ~删除~ `代码` ```块``` > 引用、链接、@某人、#频道、:emoji:）、表情反应（悬停出现 👀 ✅ 👍 回复；点表情走 Slack 直连，要应用开 reactions:write 权限）、线程、附件名、频道用途与人数、@ 提人（输入 @ 弹同事名单，发出去时换成 Slack 认的 <@U…>）、搜索消息（清单页顶上）。
- **套餐份额＝最真实的数**（v19.1）：Claude Code 每轮回报本席位 5 小时窗／本周已用几成、有没有动用「额外用量」。ask ala 底部状态行一直显示；系统窗口「状态」和「用量」页各有四张卡（本周已用、5 小时窗、额外用量、账单口径）。席位是包月的，只有超过份额且开着额外用量时，超出部分才按 API 价另收；页面里的「折算 US$」只是按 API 牌价换算的相对分量，不是要付的钱。
- **连接器**（系统窗口）：只列工作台用的四个（Slack／Google Drive／Gmail／Google Calendar），它们只在 ask ala 里让 Claude Code 读写时用；页面刷新走直连，不用它们。「未授权」＝在 claude.ai 用公司账号登录 → 设置 → 连接器 → 连接，再点「重新检查」（起一个不发话的进程问状态，不花用量）。
- **四个来源都直连**（v18）：刷新不经过 Claude、不花用量——工作台自己去问各系统。系统窗口「直连」一节四张卡：
  - **网站后台**：一直直连，每 60 秒看一次，打开后台窗口时超过半分钟就现取。
  - **Slack**：粘贴 Dadi Workbench 的 User OAuth Token（xoxp-，在 api.slack.com/apps → OAuth & Permissions），保存前先用 Slack 测一遍。开着时 Slack 的读写不经过 Claude，另起一个只看 Slack 的快轮（15 秒，闲时或不在前台 60 秒）；令牌被撤销自动退回经 Claude 读取。
  - **Google Drive**：装了 Google Drive 桌面版、登录公司账号（共享云端硬盘里有「大地 AI 工作任务」）就自动直连，不用设置；文件夹、清单、md／txt／PDF／docx 正文、建文件、改名、移动、进回收站都在本机做；Google 文档／表格的正文本机只有一个指针，这一项仍交给连接器（现起一个取数进程，三四秒）。
  - **Gmail**：填 Google 账号的「应用专用密码」（myaccount.google.com/apppasswords，要先开两步验证）和邮箱地址（装、换、删密码要切成「管理员」人物），保存前先登录 IMAP 试一遍；只读收件箱里没读的邮件，不发信。正文＋附件这种套了两层的邮件也能取到正文摘要；Gmail 掐线立刻报错、不干等。密码只存本机，不进日志、不交给模型；被拒自动退回经 Claude 读取，每 5 分钟再试一次。
- **刷新节奏**：Slack＋Drive 都直连时有动静每 30 秒一轮、5 分钟没碰改 2 分钟一轮，Gmail 直连每 2 分钟看一次收件箱，这时不再养取数进程；只要有一个还经 Claude，就按原来的有动静 3 分钟、闲时 10 分钟，Gmail 经 Claude 时每小时一次。页面不在前台不刷。情报汇总：当天有例行汇总就用那条，否则有新消息时工作台自己用 Claude Code 写一份，自动最多半小时一次，手动「重新汇总」随时。

## 3.5 任务窗口与「接入我的 Claude」（v25）

目的：你平时用的 Claude Code（有记忆、能读写桌面文件）直接连到这台工作台，提交每日工作、存档、存记录；工作台不另起界面，全部在原来的窗口里。

- **竖栏「任务」**：全公司一张任务表。页签＝任务｜待批准｜经验｜小结｜存档｜成员・分工｜接入。派任务可选同事，不选就按分工表；任务点开能留言、改状态、转人。有人派活、留言、做完，工作台弹桌面通知，竖栏角标加一。
- **情报顶上的「今日」**：我名下没做完的任务。提醒型模版每天 9 点按规则生成任务（同一件事不重复建）。
- **固定做法＝模版**：模版编辑里选「是哪一类任务的固定做法」。谁的 Claude 领这类任务，这条模版的规则一起给它。
- **越用越懂**：各人的 Claude 做完事把经验交上来（待批准）。管理员在「待批准」里点批准，这条经验写进对应模版的「已采用的经验」、版本加一；点作废就不采用。新经验可以取代旧的，可以设复查日期。
- **自动开工和收工**：接入后，开对话自动带入今天的任务和新通知；对话结束自动整理一份小结交上来（做完的、学到的、没做完的），私事不交。
- **存档**：对 Claude 说「把这个文件存档」，文件存到运行数据目录 `brain/files/`，在「存档」页签下载。
- **接入**：双击 `接入我的Claude.command`（会改你自己的 Claude 设置，所以必须本人运行；原设置备份成 `settings.json.before-dadi`）。同事在「成员・分工」里加人，页面给钥匙和一行安装命令。现在只听本机，搬到 Mac mini 并对内网开放后同事才能连。
- **守门**：成员默认只读后台；改后台要勾权限，且仍过硬规则（不许删商品、动账号）。每把钥匙做了什么都记在「接入」页签最下面。

## 3.6 同事总览・备份・提醒・派活智能体（v26）

工作台不对同事开放。同事只用自己的 Claude Code；装一次「接入」之后，数据自己传到主机，你在「任务」窗口里看。

**数据怎么自动过来（同事什么都不用做）**

| 时机 | 传什么 | 靠什么 |
|---|---|---|
| 开对话、每句话、每次答完、对话结束 | 报一声「我在」：只有时间和所在文件夹 | Claude Code 的五个钩子 |
| 对话结束、压缩前 | 一份小结：做完了什么、没做完什么、学到什么（私事不收） | 钩子起一个便宜的模型整理 |
| 任务状态变化 | 开始做、做完、卡住、留言 | Claude 调任务表的工具 |
| 每 15 分钟 | Claude 的记忆・规则・技能＋指定的工作文件夹（只传有变化的） | 后台定时（launchd，每分钟醒一次） |
| 每分钟 | 取到点的提醒和新通知，弹桌面通知 | 同上 |

不传：对话记录文件本身（.jsonl）、登录凭证、钥匙。设置文件里的环境变量值会打码。对话另走「精简对话」：本人下班确认后才发（见 3.11）。

**「任务」窗口的页签**

- **同事**：每人一张卡，六项——任务进度、今天的进度、消耗的时间、认真程度、贡献、电脑备份；下面是「解决了什么」「还没解决」。展开看 7 天时间、小结、提醒。最上面是智能体写的今日简报。
  - 时间只算和 Claude 一起干活的（相邻两次心跳隔不到 10 分钟算连续），加上同事自己报的线下时间（对 Claude 说「刚才打包了一小时」）。
  - 认真程度不打分，只列能算出来的数：按时完成率、被退回次数、交活有没有证据、有没有交小结。
- **派活**：派活智能体的开关、时间、模型，「现在排一次」；定时提醒的清单和表单。
- **存档**：存档文件＋每个同事电脑的备份情况。

**派活智能体**：主机上的一个 Claude。到点先按规则生成任务，再读全员数据（任务、逾期、上次没做完的事、分工表、提醒），给每个人建任务、定提醒，最后写简报。它只有排活那几样工具，改不了后台，也不干具体的活。默认关着；每次约一两分钟。分工表在「成员・分工」里定，它按那张表分人。

**同事电脑上的命令**（都在 `~/.dadi-brain/dadi`）

```bash
dadi folder add ~/Desktop/商品素材   # 这个工作文件夹也备份
dadi sync                            # 现在备份一次
dadi status                          # 连的是哪、上次备份
dadi restore --apply                 # 换电脑：把自己的记忆和规则取回并放进 Claude
dadi restore --person 名字 --apply   # 接手别人的工作：先在「成员・分工」里给他选「接手谁的工作」
```

每人在主机上的备份上限 5GB。时间：相邻两次心跳隔不到 10 分钟算连续在做；Claude 自己连续干活时，后台每分钟看对话记录有没有在写，在写就报一声，所以长任务也连续；按 Esc 打断等没有收尾信号的，最多算 20 分钟。工作台自己起的 Claude（ask ala、巡检、派活）不触发这些钩子，ask ala 由工作台直接替你记时间。备份时文本里像钥匙、令牌、密码的一段会换成「（已隐藏）」。恢复时已有的文件不覆盖（要覆盖加 `--force`）；原来的设置文件存成 `settings.restored.json`，不替换现在的设置；用户名不同也能对上记忆的文件夹。备份在主机数据目录 `brain/backup/<人>/`，被覆盖的旧版留 60 天，同事那边删了主机也不删。

**开始前要告诉同事**：会备份到公司机器上的有哪些（上表），用来做什么；想停可以把 `~/.dadi-brain/config.json` 里的 `sync` 或 `digest` 改成 `"off"`。

## 5. 安全边界

- 服务只听本机（127.0.0.1）；接口要带本次启动随机生成的口令（写在页面里），挡的是别的网站：跨站请求读不到页面，也就拿不到口令。同一个 macOS 账号下的本机程序能读到页面，所以真正的边界是这台电脑上你自己的账号，不要在共用账号的电脑上开着。
- 后台只认 `/admin/` 下的路径，账号与登录接口对模型关闭；所有写操作（确认卡的允许/拒绝、后台改动、页面发起的 Slack/Drive 写、人物切换）记在 `log/audit.log`，系统窗口「最近操作」页能看、能筛选。
- 后台 token、Slack 令牌、Gmail 应用专用密码都存本机 0600 文件，不交给模型、不写日志；不保存后台登录密码。硬规则（`hooks/guard.mjs`）连读都拦：模型用 Read／Grep／命令碰运行数据目录一律拒，只有附件子目录 `uploads/` 例外；`rm -r` 逐个目标看，全在临时目录才放行；密钥文件按路径段认（credentials、secrets、.pem/.p8/.p12/.key），secretary_notes.md 这类不误伤。
- Drive 直连按编号找文件时核对扩展属性：文件在网页端被移走、原位又出现同名新文件，不会认错；板块和状态文件夹不能改名、移动、删除；Google 文档指针不在本机复制（交给连接器做真正的副本）；一次查多个文件夹只要有一个本机找不到就整条交给连接器，不给残缺结果。

## 7. 排查

- 页面提示「Claude Code 还没有登录」：终端 `claude auth login`。
- 一直「正在读」：看 `log/service.log`；放一个空文件 `~/Library/Application Support/dadi-workbench/debug` 可把每个 Claude Code 进程的往来存进 `log/`。
- 接口返回 401：服务重启过，页面会自动重开；没重开就手动刷新。
- 后台服务起不来、`service.log` 没有新内容：plist 里写的是 node 的绝对路径，node 升级或搬了位置后要重新双击「安装后台服务.command」。
- Slack 直连保存不上、提示「应用缺权限」：到 api.slack.com/apps 的 Dadi Workbench → OAuth & Permissions 把缺的 scope 加上（列会话、成员名单、搜索、读频道和私聊消息是必须的），重新安装应用后再粘贴令牌。

### 3.9 v28 闭环一：任务 产生→看到→做→结束→历史（20261111）
